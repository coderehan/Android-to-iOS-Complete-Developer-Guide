# 40 - Resources: Where to Learn iOS as an Android Developer

> Curated starting points — official docs first, then community resources that are especially good at bridging from a "coming from Android" perspective.

---

## 📘 Official Apple Resources

| Resource | What it covers |
|---|---|
| [Swift.org Documentation](https://www.swift.org/documentation/) | The language itself — start here for syntax, closest to Kotlin docs |
| [Apple Developer — SwiftUI Tutorials](https://developer.apple.com/tutorials/swiftui) | Official hands-on SwiftUI tutorial, similar spirit to Android's official Compose codelabs |
| [Human Interface Guidelines (HIG)](https://developer.apple.com/design/human-interface-guidelines) | Apple's design system reference — the iOS equivalent of Material Design guidelines |
| [Apple Developer Documentation](https://developer.apple.com/documentation) | API reference for every framework (UIKit, SwiftUI, Core Data, etc.) |
| [WWDC Videos](https://developer.apple.com/videos/) | Apple's annual conference sessions — deep dives on every new API, free and excellent |

---

## 🎓 Structured Courses

- **100 Days of SwiftUI** (Hacking with Swift, free) — the most commonly recommended structured path for developers new to Swift/SwiftUI; comparable in spirit and pacing to Android's official Compose Pathway.
- **Stanford CS193p** (free, university-level, YouTube) — rigorous, in-depth SwiftUI course from Stanford, updated yearly.

## 🛠 Tools Worth Installing Early

| Tool | Purpose |
|---|---|
| SwiftLint | Linting — set up early, same reasoning as adopting ktlint/detekt on day one of an Android project |
| SF Symbols (Apple app) | Browse/search Apple's built-in icon set — the iOS equivalent of Android's Material Icons browser |
| Proxyman or Charles Proxy | Network request inspection (fills the gap left by no built-in Xcode network inspector — see [27 - Debugging](./27-Debugging.md)) |
