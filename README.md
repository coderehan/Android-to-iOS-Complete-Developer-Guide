# 🚀 iOS for Android Developers

> A complete roadmap for Android developers who want to learn iOS development.

This repository is designed specifically for Android developers who already know **Kotlin, Jetpack Compose, MVVM, Clean Architecture, Retrofit, Room, Hilt**, etc., and want to transition into **iOS (Swift + SwiftUI)** without reading hundreds of pages of documentation.

Instead of learning everything from scratch, every concept is explained by comparing it with Android development.

# 📱 Android vs iOS

| Android               | iOS                          |
| ---------------------- | ----------------------------- |
| Kotlin                 | Swift                         |
| XML                     | Storyboard / SwiftUI          |
| Jetpack Compose         | SwiftUI                       |
| Activity                | UIViewController / Scene      |
| Fragment                 | UIViewController (child)      |
| RecyclerView             | UITableView / UICollectionView / List (SwiftUI) |
| Navigation Component     | NavigationStack (SwiftUI)     |
| ViewModel                 | ObservableObject / @Observable |
| LiveData / StateFlow      | @Published / Combine          |
| Retrofit                 | URLSession / Alamofire        |
| Room                      | Core Data / SwiftData         |
| SharedPreferences          | UserDefaults                  |
| Coil                        | Kingfisher / SDWebImage       |
| Hilt / Dagger                | Swift native DI / Factory / Resolver |
| WorkManager                   | BGTaskScheduler                |
| CameraX                        | AVFoundation                   |
| Google Maps                     | MapKit                         |
| Firebase                          | Firebase (iOS SDK)             |
| Gradle                              | Xcode Build System / Swift Package Manager |
| APK / AAB                             | IPA                             |
| Google Play Console                     | App Store Connect               |
